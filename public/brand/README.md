# Silo Works marks

The horizontal lockup and silo illustration are vector SVGs inspired by the supplied brand board. The icon uses fewer details for small-size legibility. All lettering is outlined, so logo rendering has no font or network dependency.

Wordmark lettering is derived from Anton Regular by Vernon Adams (SIL Open Font License, included in Anton-OFL.txt). Font source: https://github.com/google/fonts/tree/main/ofl/anton

The heritage signature uses Inter SemiBold (SIL OFL; see ../fonts/inter-OFL.txt).

Anton source TTF SHA-256: `a4ba3a92350ebb031da0cb47630ac49eb265082ca1bc0450442f4a83ab947cab`.

The SVGs use prairie ink (#263E4A), paper (#F6F0E4), and a darker rust (#9B5034). They deliberately omit weathering so they remain crisp at editor-header sizes.
